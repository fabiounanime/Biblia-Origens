## Claude Code

- Este projeto roda no app desktop do Claude Code no Windows: o Bash é Git Bash; use caminhos com `/` e aspas duplas em globs de `npm` scripts.
- Memória do Claude: índice em `MEMORY.md` da pasta de memória do projeto (carregado em toda sessão). Regras duráveis do projeto vão para os documentos versionados, não para a memória.
- Navegador: o painel de navegador do app e o Playwright (já no projeto) servem para conferir telas; use o login de teste combinado com o dono do projeto, sem gravá-lo em arquivos.
